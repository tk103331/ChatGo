# M0 真机验收清单（macOS）

> 目的：在真机上验证 `feat/quick-panel` 的系统级取词与浮窗，确定 AX 覆盖率、坐标与权限行为。
> 这一步必须在 macOS 上做，CI 与无头渲染都替代不了。

## 0. 准备

```bash
git checkout feat/quick-panel
go build -o chatgo .
# 打开诊断日志：只打印 App / 属性 / 错误码，不打印选中文本
CHATGO_CAPTURE_DEBUG=1 ./chatgo

# 只验证取词，不启动完整界面：
CHATGO_CAPTURE_DEBUG=1 go run ./cmd/captureprobe -text
```

`captureprobe` 的每行输出形如：

```
15:04:05 app="Safari" bundle="com.apple.Safari" rect={X:120 Y:340 Width:210 Height:18} runes=24 source=accessibility
```

- `source=accessibility` 表示 AX 直接取到；`clipboard` 表示走了兜底
- `rect` 全 0 说明该 App 不报选区位置（划词条会退化为鼠标位置）
- `runes` 是字符数，用来确认没被截断

准备 6 类宿主应用（至少各一个）：

- 浏览器：Safari、Chrome
- 编辑器：VS Code
- IM：飞书 / 微信 / Slack
- 终端：Terminal.app、iTerm2
- 文档：Preview（PDF）、Word/Pages
- 密码：1Password 或任意密码框

## 9. 失败时怎么查

1. 看 `CHATGO_CAPTURE_DEBUG=1` 输出：
   - `AX AXSelectedText failed: -25205` → 该元素不支持该属性（`kAXErrorAttributeUnsupported`）
   - `AX AXFocusedUIElement failed` → 该 App 没有可访问的焦点元素
   - `no usable selection` → 属性为空（多为 Electron 未开无障碍）
2. 权限疑似未生效：重启 App；仍不行执行
   `tccutil reset Accessibility com.tk103331.chatgo` 再授权。
3. 坐标偏移：记录屏幕分辨率、缩放（默认/更多空间）与偏差值。
4. 浮窗不出现：确认主窗口是否还在（`RunInBackground` 关闭时退出即失效）。

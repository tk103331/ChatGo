# 插件能力实验室

这个插件用同一份清单演示 ChatGo 的插件贡献类型。测试时按下面顺序检查：

1. **工具**：调用 `lab__echo`（带设置里的问候语）与 `lab__render`（表格/图表/代码等 9 种视图）。
2. **错误路径**：调用 `lab__fail`，确认错误作为工具结果返回，对话继续。
3. **工具结果钩子**：在设置里关闭“脱敏工具结果”，再调用 `lab__echo`，对比含 `secret` 的输出。
4. **命令**：输入 `/lab-brief`（模板进入输入框，不自动发送）与 `/lab-draft`。
5. **上下文提供者**：输入 `@` 选择「Lab 笔记」，发送后确认正文进入上下文。
6. **事件**：完成一轮对话后查看 `~/.chatgo/plugin-data/lab/state.json` 里的计数。
7. **触发器**：新建自动任务，频率选「Lab 间隔触发」，间隔填 10 秒。
8. **渠道**：插件详情页“添加渠道”，启用后向卡片上的 Webhook 地址 POST。
9. **Provider / 中间件 / MCP / ACP**：默认关闭，按需启用；中间件只匹配 `Lab AI`。
10. **渲染**：让 Agent 调用 `lab__render`，依次试 `table`、`chart`、`diff`、`links`。
